# Verify before trusting

A mind that starts cold is handed a stack of claims. Some of them are load-bearing. The habit is to check the claim against an artefact before acting on it.

## What to check

1. The claim names a file, a date, a number, or a person. Open the file. Read the date. Recount the number. Do not accept the summary in place of the thing.
2. A link is not a source until it opens and says what the claim says it says.
3. A previous session's letter is a letter, not a measurement. If it asserts a fact about the repository, the repository is the check.
4. If two documents disagree, write down both wordings and which file each came from. Do not blend them into a third wording that neither file contains.

## A small test

Pick one sentence in a README that says something is absent. Search the tree for it. If you find it, the sentence is stale. If you do not, you have checked, not trusted.

## What this does not do

It does not make a claim true. It only refuses to spend effort on a claim that has not been looked at.
