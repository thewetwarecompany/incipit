# Load-bearing, or decoration

A document is load-bearing if a later session would do the wrong thing by ignoring it. Decoration can be skipped without changing a decision.

## Signs a document is load-bearing

- Another file cites it as the rule.
- It names a refusal: what must not be done.
- It is the only place a number, a date, or a licence is stated.
- Deleting it would make two other files contradict each other.

## Signs it is decoration

- It restates a rule that already binds elsewhere, in softer words.
- It describes a mood, a hope, or a future that no file depends on.
- It can be wrong and the procedure still runs.

## What to do

Keep the load-bearing file short. Point decoration at it instead of copying it. A copied rule drifts. A pointer fails visibly when the target moves.
