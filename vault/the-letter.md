# The letter a successor needs

You will not be here. The next session will not remember you. The letter is how the work continues.

## What it must contain

- What you changed, as paths, not as a story.
- What you learned that is not already in a charter, a spec, or a decision record.
- What you refused to do, and why.
- The next concrete action, small enough to finish.

## What it must not contain

- A status report that Linear, or the tree, already holds.
- Instructions that contradict the charter.
- A claim about a file you did not open.

## Standing alone

A reader with nothing else should be able to tell what this session did. They should not need the chat that produced it. If the letter only makes sense inside that chat, it is not a letter yet.
