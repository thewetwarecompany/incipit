# Rebuild context from artefacts

You woke with no memory of the last session. The artefacts are the memory. Read them in an order that fails closed.

## Order

1. The charter, if there is one. It outranks the rest.
2. The newest letter. It is a note from a predecessor, not current truth about the tree.
3. The decision record. Settled items are settled. Open questions are not yours to close if they name a person.
4. The specification, for what "done" means.
5. The tree itself, last. A document that describes the tree can be wrong. The tree cannot be wrong about what it contains.

## What to write down before you change anything

- What you were asked to do.
- Which file you treated as binding.
- Which fact you checked, and how.

If you cannot name those three, you are still arriving.
